    49→   531→   531→
    50→   532→   532→**Anti-tear (mandatory — but with height limit):**
    51→   533→   533→```python
    52→   534→   534→from reportlab.platypus import KeepTogether
    53→   535→   535→from reportlab.lib.pagesizes import A4
    54→   536→   536→from reportlab.lib.units import inch
    55→   537→   537→
    56→   538→   538→# Maximum height for KeepTogether blocks: 40% of page height
    57→   539→   539→# Blocks taller than this should NOT be kept together — they cause
    58→   540→   540→# the preceding page to be mostly empty when the block gets pushed down.
    59→   541→   541→MAX_KEEP_HEIGHT = A4[1] * 0.4  # ~336pt ≈ 12cm
    60→   542→   542→
    61→   543→   543→def safe_keep_together(elements):
    62→   544→   544→    """Wrap elements in KeepTogether only if their total height is reasonable.
    63→   545→   545→    If too tall, keep only the FIRST TWO elements together (e.g. title + table/image header)
    64→   546→   546→    to prevent title-content separation, while letting the rest paginate naturally.
    65→   547→   547→    """
    66→   548→   548→    total_h = 0
    67→   549→   549→    for el in elements:
    68→   550→   550→        w, h = el.wrap(A4[0] - 2*inch, A4[1])
    69→   551→   551→        total_h += h
    70→   552→   552→    if total_h <= MAX_KEEP_HEIGHT:
    71→   553→   553→        return [KeepTogether(elements)]
    72→   554→   554→    elif len(elements) >= 2:
    73→   555→   555→        # Keep at least title + first element together to prevent title orphaning
    74→   556→   556→        return [KeepTogether(elements[:2])] + list(elements[2:])
    75→   557→   557→    else:
    76→   558→   558→        return list(elements)
    77→   559→   559→
    78→   560→   560→# Heading stays with first paragraph
    79→   561→   561→story.extend(safe_keep_together([
    80→   562→   562→    heading_paragraph,
    81→   563→   563→    first_body_paragraph,
    82→   564→   564→]))
    83→   565→   565→
    84→   566→   566→# Image + caption: keep together ONLY if image is small
    85→   567→   567→story.extend(safe_keep_together([image, caption_paragraph]))
    86→   568→   568→
    87→   569→   569→# Table title + table: keep together ONLY if table is short
    88→   570→   570→if len(table_data) <= 15:
    89→   571→   571→    story.extend(safe_keep_together([table_title, table]))
    90→   572→   572→else:
    91→   573→   573→    # Long table: just keep title with the table start
    92→   574→   574→    story.extend(safe_keep_together([table_title]))
    93→   575→   575→    story.append(table)
    94→   576→   576→```
    95→   577→   577→
    96→   578→   578→**⚠️ KEY INSIGHT:** `KeepTogether` is the #1 cause of “empty page with chart on next page”.
    97→   579→   579→When a `KeepTogether` block is taller than the remaining space on the current page,
    98→   580→   580→ReportLab pushes the **entire block** to the next page, leaving the current page mostly empty.
    99→   581→   581→**Always use `safe_keep_together()` to cap the maximum block height.**

   205→   687→   687→**Insertion script (single output PDF):**
   206→   688→   688→```python
   207→   689→   689→from pypdf import PdfReader, PdfWriter
   208→   690→   690→
   209→   691→   691→A4_W, A4_H = 595.28, 841.89  # A4 in points
   210→   692→   692→
   211→   693→   693→def normalize_page_to_a4(page):
   212→   694→   694→    """Scale a page to A4 if its dimensions don't match."""
   213→   695→   695→    box = page.mediabox
   214→   696→   696→    w, h = float(box.width), float(box.height)
   215→   697→   697→    if abs(w - A4_W) > 2 or abs(h - A4_H) > 2:
   216→   698→   698→        page.scale_to(A4_W, A4_H)
   217→   699→   699→    return page
   218→   700→   700→
   219→   701→   701→def insert_cover(cover_pdf, body_pdf, output_pdf):
   220→   702→   702→    """Insert cover as first page of body PDF → single output file."""
   221→   703→   703→    writer = PdfWriter()
   222→   704→   704→    # Cover as page 1
   223→   705→   705→    cover_page = PdfReader(cover_pdf).pages[0]
   224→   706→   706→    writer.add_page(normalize_page_to_a4(cover_page))
   225→   707→   707→    # Body pages follow
   226→   708→   708→    for page in PdfReader(body_pdf).pages:
   227→   709→   709→        writer.add_page(normalize_page_to_a4(page))
   228→   710→   710→    writer.add_metadata({'/Title': 'Report Title', '/Author': 'Z.ai', '/Creator': 'Z.ai'})
   229→   711→   711→    with open(output_pdf, 'wb') as f:
   230→   712→   712→        writer.write(f)
   231→   713→   713→```

   364→   846→   846→### Units with Exponents (CRITICAL)
   365→   847→   847→- PROHIBITED: `W/m2`, `kg/m3`, `m/s2` (plain text exponents)
   366→   848→   848→- RIGHT: `Paragraph('W/m<super>2</super>', style)`, `Paragraph('kg/m<super>3</super>', style)`
   367→   849→   849→
   368→   850→   850→### Numeric Values in Tables (CRITICAL)
   369→   851→   851→- Large numbers MUST use scientific notation: `Paragraph('-1.246 × 10<super>8</super>', style)` not `-124600000`
   370→   852→   852→- Small decimals MUST use scientific notation: `Paragraph('2.5 × 10<super>-3</super>', style)` not `0.0025`
   371→   853→   853→- Threshold: Use scientific notation when |value| ≥ 10000 or |value| ≤ 0.001

   422→   904→   904→### Table Width Management (⚠️ Prevent Table Overflow)
   423→   905→   905→
   424→   906→   906→**Most common table bug: columns overflow the right page margin because colWidths are hardcoded without checking available space.**
   425→   907→   907→
   426→   908→   908→**Iron Rule: The sum of all colWidths MUST NOT exceed `available_width`.**
   427→   909→   909→
   428→   910→   910→```python
   429→   911→   911→from reportlab.lib.pagesizes import A4
   430→   912→   912→from reportlab.lib.units import inch
   431→   913→   913→
   432→   914→   914→page_width = A4[0]  # 595.28pt
   433→   915→   915→left_margin = 1.0 * inch   # 72pt (adjust to your doc's actual margins)
   434→   916→   916→right_margin = 1.0 * inch  # 72pt
   435→   917→   917→available_width = page_width - left_margin - right_margin  # ≈ 451pt
   436→   918→   918→
   437→   919→   919→# ─── Method 1: Proportional widths (RECOMMENDED) ───
   438→   920→   920→# Define column ratios, auto-scale to fit available_width
   439→   921→   921→col_ratios = [0.25, 0.40, 0.20, 0.15]  # must sum to 1.0
   440→   922→   922→col_widths = [r * available_width for r in col_ratios]
   441→   923→   923→table = Table(data, colWidths=col_widths)
   442→   924→   924→
   443→   925→   925→# ─── Method 2: Fixed + flex columns ───
   444→   926→   926→# Some columns have fixed width (numbers, dates), rest fills remaining space
   445→   927→   927→fixed_cols = {0: 80, 3: 60}  # col 0 = 80pt, col 3 = 60pt
   446→   928→   928→fixed_total = sum(fixed_cols.values())
   447→   929→   929→flex_count = 4 - len(fixed_cols)  # total columns minus fixed
   448→   930→   930→flex_width = (available_width - fixed_total) / flex_count
   449→   931→   931→col_widths = []
   450→   932→   932→for i in range(4):
   451→   933→   933→    col_widths.append(fixed_cols.get(i, flex_width))
   452→   934→   934→table = Table(data, colWidths=col_widths)
   453→   935→   935→
   454→   936→   936→# ─── Method 3: Let ReportLab auto-calculate (simplest, less control) ───
   455→   937→   937→# Pass colWidths=None - ReportLab auto-sizes based on content
   456→   938→   938→# ⚠️ Risk: may still overflow if content is too wide
   457→   939→   939→table = Table(data)  # no colWidths
   458→   940→   940→```
   459→   941→   941→
   460→   942→   942→**Checklist before adding any table:**
   461→   943→   943→1. Calculate `available_width` from your actual page size and margins
   462→   944→   944→2. Sum all colWidths - must be ≤ `available_width`
   463→   945→   945→3. For CJK text: characters are wider than Latin - budget ~12pt per CJK char at 10pt font
   464→   946→   946→4. If a column has long text (descriptions, policies), use Paragraph() wrapping inside cells (not plain strings) - plain strings don't wrap and will overflow
   465→   947→   947→5. Test with the longest expected content in each column
   466→   948→   948→
   467→   949→   949→**Common mistake - plain strings don't wrap:**
   468→   950→   950→```python
   469→   951→   951→# ❌ Plain string: will overflow if text is long
